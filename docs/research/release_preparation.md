## Human release gate

1. Obtain and record an outside researcher's **actual** source-to-table/figure reproduction and scientific review; resolve substantive issues with traceable changes and re-review.
2. Review the July contrast and known limits. Decide whether the tested scope is sufficient for a release; do not claim several physical environments from two Wind windows.
3. After explicit authorization, create a release-specific version, changelog entry, tag and citation/DOI record. Rebuild from that exact clean tagged source; run `npm test`, `npm run build:standalone`, individual and bundle replay, and inspect the generated browser/standalone identities. Compare published artifact hashes with the tested files. The final tag and docs must agree.
4. Publish only after the release DOI and attribution are verified. Keep v1.1.0 history unchanged. Record corrections and compatibility/deprecation effects in future releases.

Until independent reproduction and a verified Release 2 tag/DOI exist, this document cannot assert final release readiness. The checkpoint and release steps remain subject to human approval.

## Software-paper decision

**No paper outline is prepared in this pass.** The current code is modular and locally testable, and the repository has MIT licensing, documentation, CI and tagged v1 releases. However, the local Git history's initial public-release commit is dated 2026-08-05, only weeks before this 2026-09-28 review; actual public visibility and sustained use must be checked independently. More decisively, no outside researcher has yet supplied the required meaningful research-use/reproduction report. The [current JOSS submission guidance](https://joss.readthedocs.io/en/latest/submitting.html) requires more than six months of public development and demonstrated research impact, and asks web-based software to expose a locally testable core. Revisit journal suitability after a real release and outside use; do not treat the Wind case study alone as a paper or a new physical discovery. Any future manuscript needs an accurate, author-reviewed AI-assistance disclosure.
