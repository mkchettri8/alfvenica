# Wind pathway reproduction guide

This guide describes how to regenerate the accepted Wind H1 results from the source CDF and compare them with a supplied analysis bundle. A matching replay establishes computational reproduction under its declared tolerance; it does not establish source-measurement quality or scientific correctness.

## Materials

Use the **primary** `analysis.json`, `summary.csv`, `plotting-data.csv`, `figure.svg`, `methods-draft.md`, prepared CSV and JSON sidecar, fit-attribute record, and `README-replay.txt` generated by `npm run create:analysis`. Consult the [Pass 1 source manifest](../../examples/wind_pilot/manifest.json), [Wind case study](wind_case_study.md), [variable dictionary](wind_variables.md), and [known limits](known_limits.md). Retrieve the original CDF from the manifest's public CDAWeb URL; it is **not** included in the analysis bundle. The bundle embeds its prepared input so that a calculation replay can be attempted before CDF retrieval. Neither replay nor a matching digest certifies the source measurements.

Record the exact full Git source commit and source manifest for the checkout used. The bundle's `producer.sourceIdentity` covers only its listed file subset and is a supplemental check, not the complete source anchor.

The primary file is `wi_h1_swe_20200101_v01.cdf`, 642,922 bytes, SHA-256 `77a26a8a939fb2cc280c8ac1f9e1cb7f10da40e279ed61842878f7fc4a9a0aa3`. Its product is `WI_H1_SWE` ([NASA dataset DOI](https://doi.org/10.48322/nasd-j276)); the requested half-open spectrum-start window is `2020-01-01T16:00:00.000Z` to `2020-01-01T18:00:00.000Z`. Cite the dataset and actual file version. The optional `WI_H0_MFI` file in the manifest was inventoried but is **not** an input to these four results.

## Reproduction procedure

1. Record OS, Node version, Python/package versions if using the CDF preparer, and repository checkout/tag. Check that the supplied bundle's `producer.sourceIdentity`, formula identity and dataset/file declarations are inspectable.
2. Fetch the CDF from the manifest URL; check filename, byte count and SHA-256. Read the CDF product/version, units, `fit_flag`, thermal-speed, GSE field and fit-sigma attributes against the sidecar and [variable dictionary](wind_variables.md). Record any discrepancy; do not silently patch the sidecar.
3. In a clean checkout of the **same tested source** run `npm test`, then prepare the files (pandas, NumPy and cdflib are only local preparation dependencies):

   ```bash
   python3 examples/wind_pilot/prepare_pass4_local_cdf.py wi_h1_swe_20200101_v01.cdf reproduced.csv reproduced-metadata.json
   python3 examples/wind_pilot/verify_pass5_uncertainty.py wi_h1_swe_20200101_v01.cdf > reproduced-fit-attributes.json
   npm run create:analysis -- reproduced.csv reproduced-metadata.json reproduced-fit-attributes.json reproduced-output
   npm run replay:analysis -- reproduced-output/analysis.json
   ```

4. Also run `npm run replay:analysis -- supplied-primary/analysis.json`. Compare the regenerated `summary.csv`, `plotting-data.csv`, and `figure.svg` with the supplied files. Check each quantity's calculated count and median difference, the largest absolute and relative difference in corresponding row values, any differing sample IDs/warning IDs/statuses, and whether the SVG is identical or how it differs. The replay allowance is relative `1e-12`, absolute `0` for binary64 values; this is computational tolerance, not measurement uncertainty. Exact-byte agreement is useful but not required for scientific agreement.
5. Check whether fit-flag exclusions, time support, units, proton-only mass density, temperature conventions, evidence labels and limitations support the stated **numerical** claims. Record any misleading or missing label. Do not infer a mode or total beta from the figure.

Document any numerical or scientific discrepancy with the source identity and affected rows or quantities. The [contrasting July case](wind_case_study.md#reproduce-the-contrasting-case-locally) uses the same comparison approach with its own manifest file and interval.
