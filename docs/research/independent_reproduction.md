Report any discrepancy; do not silently patch the sidecar.
3. In a clean checkout of the **same tested source** run `npm test`, then prepare your own files (pandas, NumPy and cdflib are only local preparation dependencies):

   ```bash
   python3 examples/wind_pilot/prepare_pass4_local_cdf.py wi_h1_swe_20200101_v01.cdf reviewer.csv reviewer-metadata.json
   python3 examples/wind_pilot/verify_pass5_uncertainty.py wi_h1_swe_20200101_v01.cdf > reviewer-fit-attributes.json
   npm run create:analysis -- reviewer.csv reviewer-metadata.json reviewer-fit-attributes.json reviewer-output
   npm run replay:analysis -- reviewer-output/analysis.json
   ```

4. Also run `npm run replay:analysis -- supplied-primary/analysis.json`. Compare **your** `summary.csv`, `plotting-data.csv`, and `figure.svg` with the supplied files. Report each quantity's calculated count and median difference, the largest absolute and relative difference in corresponding row values, any differing sample IDs/warning IDs/statuses, and whether the SVG is identical or how it differs. The replay allowance is relative `1e-12`, absolute `0` for binary64 values; this is computational tolerance, not measurement uncertainty. Exact-byte agreement is useful but not required for scientific agreement.
5. Independently judge whether fit-flag exclusions, time support, units, proton-only mass density, temperature conventions, evidence labels and limitations are sufficient for the stated **numerical** claims. Note any misleading or missing label. Do not infer a mode or total beta from the figure.

The reviewer should return the completed report to the maintainer through a mutually agreed channel. Attribution or public posting needs the reviewer's agreement. Substantive issues should be logged with a proposed resolution and rechecked before a release.
