# Independent reference benchmarks

This directory contains a frozen, reproducible evidence artifact for the small
set of Alfvenica validation records whose expected values have an independent
lineage. The generator deliberately declares its own source constants and uses
ordinary arithmetic. It must not import `plasma-physics.js`,
`formula-registry.js`, `validation.js`, or `app.js`.

`benchmarks.json` is generated by
`generate-reference-benchmarks.js`. Each record identifies its definition,
input state, source locator, constants revision and uncertainty, generation
method, reference-uncertainty budget, software comparison rule, semantic evidence class, and verification
status. The independent `expectedValue` is the unrounded binary64 result of the
documented definition. The NRL three-significant-digit value is retained only
as `sourceComparison.publishedValue`; the former Alfvenica value is retained
only as `legacyV101Target` audit metadata and is not used for pass/fail. The
artifact contains no volatile timestamp, and its byte representation is part of
the test contract.

The scientific sources are:

- A. Beresnyak, *2023 NRL Plasma Formulary*, “Fundamental Plasma Parameters,”
  printed page 28. The coefficient forms provide an external cross-check on the
  independently evaluated definitions.
- *2022 CODATA Recommended Values of the Fundamental Constants of Physics and
  Chemistry*, NIST SP 959 (May 2024), pages 1–2.
- BIPM, “SI base unit: kelvin (K),” for the exact SI relationship between the
  kelvin and the Boltzmann constant.

NIST SP 959 reports parenthetical one-standard-deviation uncertainties. Exact
SI defining constants carry zero standard uncertainty in the artifact. For
non-exact constants, the artifact records both absolute and NIST-reported
relative standard uncertainty: `1.6e-10` for vacuum permittivity and `3.1e-10`
for both electron and proton mass.

`referenceUncertainty` records the sum of absolute sensitivity-weighted CODATA
relative standard uncertainties and a separately labelled expanded relative
uncertainty with coverage factor 2. These quantities describe the reference
quantity. The coverage factor is not assigned an exact confidence level, and
neither uncertainty participates in software pass/fail.

`softwareComparison` is separate and uses ULP distance only. Each fixed
benchmark is evaluated with the same explicit ordered binary64 operations in
the independent and production paths. The expressions avoid exponentiation,
reassociation, and intermediate decimal rounding; `Math.sqrt` receives the
same binary64 argument in both paths. Therefore the derived tolerance is zero
ULP. The comparator measures the absolute difference between unsigned 64-bit
encodings of finite non-negative values. Tests exercise the comparator and all
seven anchors under the supported Node.js 24 runtime.

The proton gyrofrequency target is intentionally absent: the existing v1.0.1
target does not have a documented rounding lineage precise enough for this
artifact. Convention-sensitive thermal speeds and gyroradii are also excluded.
Collision coefficients, Coulomb logarithms, Hellinger fits, and reduced KAW
expressions remain outside this independent numerical-reference artifact even
where Scientific Resolution Pass 1 has resolved their terminology, scope,
source-domain metadata, or an analytical equation identity. They must not be
promoted to `A_REFERENCE` without an independently anchored published numerical
target and reproducible lineage. The remaining quarantined items are likewise
outside this artifact.

To regenerate and audit:

```bash
npm run generate:reference
node tests/reference.test.js
sha256sum tests/reference/benchmarks.json
```

Review the generator, the frozen JSON diff, and the reference test together.
Creating a JSON record does not by itself qualify a validation record as
`A_REFERENCE`; the source, definition, constants, method, and independence
checks must all be satisfied. The test also proves that independent targets are
not the legacy v1.0.1 values and that they still reproduce the separately stored
NRL coefficients at the source precision.
