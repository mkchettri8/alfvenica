# Security policy

Alfvenica is a static browser application. It does not require accounts, a database, or server-side processing, and calculation inputs are not intentionally transmitted.

Please do not open a public issue for a suspected security vulnerability. Report it privately to **mkchettri.22pdpy03@sikkimuniversity.ac.in** with a concise description, reproduction steps, affected files or URLs, and potential impact.

Scientific disagreements, formula corrections, and numerical-validation concerns are not security vulnerabilities and should be reported through ordinary issues.
